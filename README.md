# E-Commerce Product Analytics Dashboard

## Project Overview

This project is an end-to-end E-Commerce Product Analytics solution built using Selenium, Python, SQL, and Power BI. The objective of this project is to collect product data from Swiggy Instamart, perform data cleaning and analysis, and generate business insights through interactive dashboards.

---

## Project Workflow

1. Data Collection using Selenium Web Scraping
2. Data Cleaning using Pandas
3. Feature Engineering
4. Exploratory Data Analysis (EDA)
5. SQL-Based Analysis
6. Interactive Dashboard Creation using Power BI

---

## Technologies Used

* Python
* Selenium
* Pandas
* MySQL
* Power BI
* Matplotlib

---

## Dataset Information

The dataset contains product information collected from Swiggy Instamart, including:

* Product Name
* Actual Price
* Selling Price
* Discount Percentage
* Delivery Time
* City
* Product Category

---

## Feature Engineering

Additional business-focused features were created:

* Savings
* Discount Category
* Price Segment
* Delivery Category

---

## SQL Analysis

SQL queries were used to analyze:

* Total Products
* Average Selling Price
* Average Discount Percentage
* Top Savings Products
* Product Distribution Analysis

---

## Power BI Dashboard Insights

The dashboard provides insights on:

* Products by City
* Price Segment Analysis
* Discount Category Distribution
* Top Savings Products

---

## Key Outcomes

* Scraped and analyzed 1,200+ product records from Swiggy Instamart.
* Performed data cleaning and transformation using Python.
* Generated business insights through SQL queries.
* Built an interactive Power BI dashboard for visualization and decision-making.
